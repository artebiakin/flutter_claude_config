## Format

Each prompt is a single Markdown file. Keep it focused and self-contained — a prompt should make sense without the surrounding conversation context.

```markdown
# <prompt name>

**When to use:** [one-line trigger]

[The actual prompt body. Use placeholders like `<paste code here>` where the user fills things in.]
```

## Adding a prompt

1. Create `prompts/<name>.md` with the format above.
2. Add a row to the index table.
